AIM:
ㅤ
	To sketch the given drawing with dimensions using fusion 360 tool.
 
REQUIREMENTS:

1. Autodesk fusion 360
2. Windows 10
3. 16GB of RAM (integrated graphics recommend 2 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload
   
PROCEDURE:

1. Open a new file and then select the sketch icon.
2. Select the plane of sketching.
3. Use Sketching features (line, circle, arc, rectangle, polygon, etc.,) to draw to given sketch
<img width="331" height="532" alt="Screenshot 2026-10-05 105221" src="https://github.com/user-attachments/assets/1d48aa64-ed79-47cf-a708-bb2f94255227" />

4. Use sketch modifying features (trim, mirror, move, etc.,) to edit the sketch
<img width="223" height="338" alt="Screenshot 2026-10-05 105834" src="https://github.com/user-attachments/assets/14660d5b-025c-467a-b8fd-8fe1e81740b3" />

5. Use the Constraints feature and apply the Tangent tool to join the circles smoothly and create the required curves.
<img width="285" height="452" alt="Screenshot 2026-10-05 110525" src="https://github.com/user-attachments/assets/99c0e700-c7fa-41eb-b141-4564e877fb39" />

6. Draw the horizontal and vertical construction lines to mark the centre of the diagram. 
7. Draw the central circles using the Circle tool and apply the required dimensions. 
8. Draw the four outer circles at the top, bottom, left and right positions according to the given dimensions.  
9. Use the Circle tool to draw the inner circles inside the four outer circles. 
10. Draw the upper and lower outer profiles using the Line tool to connect the circular sections. 
11. Use the Tangent constraint to join the lines and circles smoothly. 
12. Apply the required Fillet radii, such as R15, R20 and R21, to form the curved edges. 
13. Draw the inner circular pattern around the centre using circles and lines. 
14. Use the Trim tool to remove the unwanted portions of the circles and lines. 
15. Use the Mirror tool to create symmetrical portions of the diagram about the centre lines. 
16. Apply all the required dimensions, including lengths, radii and distances, as shown in the  given figure.
17. Check the complete sketch and click Finish Sketch to complete the drawing.
18. Line – Used to draw the straight edges of the diagram.
    Circle – Used to create the circular holes/features in the diagram.

23. After finishing the sketch, click the Finish Sketch option to complete the sketch.
